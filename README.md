Entry for the make.fun competition
[Roast the Smart Fridge: One Line, Best Laugh Wins](https://make.fun/competitions/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9).

`main.ts` writes one roast line (at most 160 characters) about a smart fridge
to `/output/entry.txt`. Deterministic: the same line every run.

Run it with Node 22:

```sh
node main.ts
```
